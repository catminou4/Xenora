# Middleware compatibility

This directory records middleware and platform-service compatibility work that is outside the CRT, RDNA2 shader, dynamic-binary-translation and PE loader campaigns.

Start with the [Campaign E coverage inventory](coverage.md). The inventory separates implemented behavior, locally verified behavior, partial surfaces and unsupported or unavailable contracts. It does not count placeholders as verified implementations.

The work is limited to public documentation, authorized open-source materials and independently authored fixtures. Console-specific contracts that are not publicly documented are unknowns, not implementation targets.
